Política de privacidad

Última actualización: 16 de noviembre de 2026.

El «Publicador de Curiocity» es una herramienta interna que usa el canal Curiocity para publicar sus propios vídeos en sus propias cuentas de YouTube, Instagram y TikTok. No está abierta al público y no accede a cuentas de otras personas.

Qué datos usa

  • YouTube (Google): permiso para subir vídeos, poner su miniatura y publicar un comentario en el canal de Curiocity, y leer el nombre del canal para comprobar la conexión.
  • Instagram (Meta): identificador y nombre de usuario de la cuenta profesional de Curiocity, y permiso para publicar reels y comentarios en ella.
  • TikTok: nombre visible de la cuenta de Curiocity y permiso para enviar vídeos a su bandeja de borradores.

No se recogen datos de espectadores, seguidores ni de ninguna otra persona.

Dónde se guardan

Los tokens de acceso se guardan solo en el ordenador del canal, en un archivo protegido, y se usan únicamente para las acciones descritas. No se venden, no se ceden a terceros y no se usan para publicidad ni para entrenar modelos de IA.

Google API Services

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Esta herramienta usa los Servicios de API de YouTube; se aplican también las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Retirar el acceso

El acceso se puede revocar en cualquier momento desde la configuración de seguridad de Google, desde Instagram (Configuración → Apps y sitios web) y desde TikTok (Ajustes → Seguridad → Apps y servicios). Al revocarlo, los tokens dejan de funcionar y se borran del ordenador.
